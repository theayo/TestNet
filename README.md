# Замер скорости скачивания

Скрипт выполняет 10 последовательных загрузок по заданному URL. В результате показывает объём данных, среднее время запроса и скорость скачивания. Данные читаются блоками по 64 KiB и сразу отбрасываются.

## Запуск

Нужен Python 3.9 или новее. Скрипт проверен на Python 3.11 и 3.12 и использует только стандартную библиотеку. Запустите команду из папки со скриптом.

**Windows (PowerShell)**

```powershell
py speedtest.py "https://proof.ovh.net/files/1Mb.dat"
```

**Linux и macOS**

```bash
python3 speedtest.py "https://proof.ovh.net/files/1Mb.dat"
```

Пример скачивает 10 MiB за серию. С [файлом на 10 MiB](https://proof.ovh.net/files/10Mb.dat) серия скачает 100 MiB. Можно подставить свою HTTP- или HTTPS-ссылку. Параметр `--help` выводит справку.

В терминале можно запустить `py speedtest.py` или `python3 speedtest.py` без ссылки. Скрипт предложит тестовый файл OVHcloud. Нажмите Enter, чтобы скачать его, или введите свой URL. Для запуска без интерактивного терминала укажите URL в команде.

## Пример результата

```text
Выполнено запросов: 10
Скачано: 10.00 MiB (10485760 байт)
Суммарное время запросов: 5.000 с
Среднее время запроса: 0.500 с
Скорость скачивания: 2.00 MiB/s (16.78 Mbit/s)
```

## Как считается скорость

Скрипт измеряет каждый запрос через `time.perf_counter()`. В замер входят установка соединения, ожидание ответа и чтение всего тела. Общий объём считается по фактически прочитанным байтам тела ответа. Скорость зависит от выбранного сервера и маршрута до него. Даже по одному URL длительность отдельных запросов может различаться.

```text
Среднее время запроса = сумма длительностей / 10
MiB/s = байты / 1 048 576 / сумма длительностей в секундах
Mbit/s = байты × 8 / 1 000 000 / сумма длительностей в секундах
```

`MiB/s` — мебибайты в секунду, `Mbit/s` — мегабиты в секунду. Запрос просит HTTP-кэш перепроверить сохранённый ответ (`Cache-Control: no-cache`) и запрашивает тело без сжатия (`Accept-Encoding: identity`).

## Прогресс и ошибки

Итог выводится в `stdout` после 10 успешных загрузок. Если `stderr` подключён к терминалу, отдельный поток обновляет строку прогресса до четырёх раз в секунду. Строка показывает номер запроса, скачанный объём и процент, если известен полный размер.

```text
[1/10] Скачано: 5.81 MiB (58.1%)
```

После успешного замера на этой строке появляются итоговый объём и длительность запроса. На коротких загрузках может сразу появиться строка с результатом. Печать идёт параллельно с чтением ответа. В замер могут попасть накладные расходы на обновление счётчика и планирование потоков.

Ошибки выводятся в `stderr`. Цвета можно отключить переменной окружения `NO_COLOR`.

При перенаправлении вывода скрипт использует UTF-8. Кодировку можно задать переменной окружения `PYTHONIOENCODING`.

Если сервер указал `Content-Length` и закрыл соединение до конца ответа, скрипт сообщает номер запроса, ожидаемый и полученный объём в байтах. При ошибке загрузки или отмене через `Ctrl+C` итоговая скорость не выводится. Тайм-аут в 30 секунд действует на отдельные блокирующие операции подключения и чтения, поэтому полная загрузка может занять больше времени.

Коды завершения — `0` при успехе, `1` при ошибке загрузки, `2` при неверных аргументах и `130` при отмене через `Ctrl+C`.

## Тесты

```text
python -m unittest -v
```

На Windows можно использовать `py -m unittest -v`, на Linux и macOS — `python3 -m unittest -v`. Тесты с локальным HTTP-сервером проверяют порядок запросов, расчёт статистики, перенаправление, ошибку `404` и обрыв загрузки. Тесты с управляемыми часами проверяют границы замера и работу прогресса при медленном выводе в терминал.
